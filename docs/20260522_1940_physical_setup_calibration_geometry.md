## 実施したこと

v0.4 設計に沿った物理セットアップを構築。チャットの Claude と寸法調整の対話を繰り返し、最終的な配置を確定した。

### 物理セットアップ

- **板**: 木製パネルにラッピングフィルムを張り込み、 **手書きL字マーカー4頂点** で描画領域を囲む簡易キャンバス。アクリル板の代用。
- **板の向き**: **垂直** に立てかけ（θ = 0°）。当初は傾斜配置を検討したが、垂直で確定。
- **板の固定**: 床から立てかけ。Piperベースのベニア台と板下端の床は同レベル。
- **ペン**: マーカーペン1本を Piper グリッパーに **テープで固定**。専用ペンホルダーは作らず MVP 進行。
- **ペン軸**: グリッパー中心軸とペン軸がほぼ一致（中央取り付け、Y/Z オフセットは無視可能）。

### 寸法測定（実測値）

- Piperベース筒（j1モータが入る黒い円筒）の高さ: **100 mm**
- ベニア上面（Piperの取付面）から板下端表面（描画面の下端）までの高さ: **230 mm**
- Piperベース正面（j1回転軸の真下）から板表面までの **水平距離**: **325 mm**（当初 380mm → 260mm → 最終 325mm に調整）
- link6 取付フランジ面 〜 ペン先までの距離（**ツール長**）: **110 mm**

### ペン接触のための link6 座標（理論値）

ツール長 110 mm を踏まえると:

```
ペン先が板表面 (X = 325) に触れる link6.X = 325 - 110 = 215 mm

  ペンアップ位置 (板から +10mm 手前): link6.X = 205 mm
  ペン接触理論値:                   link6.X = 215 mm
  ペンダウン (+2mm 食い込み):       link6.X = 217 mm
```

## 学んだこと

### 配置調整の試行錯誤

水平距離は 38cm → 26cm → 32〜33cm（最終）の3段階で調整した。

- **38cm**: ready pose に対して自然な姿勢になるが、板上端のリーチがギリギリ (98%) で隅が届かない懸念があった。
- **26cm**: 上端は届きやすいが、 **板下端が近すぎて j3 が可動域端 (-170°) に迫る** リスクが出た。
- **32〜33cm（最終）**: ready pose との互換性と、 j3 余裕の両立点。

「距離は届く」と「姿勢は無理がない」は別の問題で、 **作業半径だけで判断すると j3 などの可動域端に引っかかる** ことを学んだ。

### 板の高さは敢えて変えなかった

筒上面から板下端までの高さは 130 mm のまま固定（200 mm 程度に上げる案もあった）。

- 上げると下端描画時の姿勢が ready pose に近づく利点はあるが、
- 上端リーチが「届かないライン」を超える懸念があり、
- 「先に下端で困らないこと」を優先した。

### ペンの剛性とツール長

グリッパー＋テープ固定だと **ペン先は剛体**。板に押し付けすぎると折損リスク、または位置誤差吸収できず精度劣化。
ペン先突出は 110 mm でやや長め。 **Y/Z 方向ストローク時にてこの原理でペン先が振動・たわむ可能性** があるが、実測で確認。

### 「板に垂直なペン姿勢」の RPY 表現

板法線が -X 方向なので、 link6 の Z軸（=ペン突出方向）を +X方向に向けたい。RPY で表すと:

```
roll  = 0°  (ペン軸まわり、任意)
pitch = -90°  (link6.Z軸を水平にする)
yaw   = 0°  (板に正対)
```

ただし piper_sdk の EndPoseCtrl の RPY 定義（ZYX オイラー / 固定座標 RPY 等）は要確認。 read_state.py で現在 RPY を読んで突き合わせる必要あり。

## Claude Code への引き継ぎ事項

### このファイルを読んだら最初にやること

1. **本ファイルと、 `20260521_1757_drawing_system_v04_design.md` の両方を読む**
2. ユーザに「読み込みました、現状こうですね」と1段落で要約して確認
3. **すぐに実機を動かさない**。Step A の `draw_square_wall.py` から着手するか、別の順序を選ぶか、ユーザと相談

### 実機を動かす前の必須確認

- CAN0 が up しているか (`bash ~/piper_ws/src/piper_ros/can_activate.sh`)
- `python3 ~/piper_test/read_state.py` で現在姿勢を確認
- ready pose v2 (j1=-45°, j2=60°, j3=-60°, j4=0°, j5=30°, j6=0°) にいない場合は、いきなり描画動作させない
- 板が正面 (j1=0°方向) にあるので、描画開始前に **j1=0° に回す** 動作が必要

### 安全マージンに関する強い要請

- **link6.X = 200mm から開始、5mm 刻みで近づける**こと
- ペン押付け量はまず **+2mm** で固定。3mm 以上の食い込みは折損リスク
- Y/Z ストロークの初回テストは **30mm 程度の小さい正方形**から。大きい矩形に挑戦するのは精度確認後

### コード配置の規約（再掲）

- 描画システム本体: `~/draw_piper/` 配下に新規作成
